# Documenta SOS — Dashboard

Dashboard web do Bloco de Notas SOS (React + TypeScript + Vite).

## Como iniciar o projeto

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

3. Abra no navegador o endereço indicado no terminal (em geral `http://localhost:5173`).

## Login do dashboard

- **Usuário:** `admin`
- **Senha:** `123`
